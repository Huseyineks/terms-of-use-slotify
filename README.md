Ограничены и запросы с одного IP-адреса, и общий объём отправок по системе. После 5 подряд неверных кодов номер блокируется на 15 минут. Достижение предела не блокирует доступ к аккаунту: вы будете направлены на подтверждение по электронной почте. Использование системы подтверждения автоматическими средствами или с чужими номерами запрещено.
